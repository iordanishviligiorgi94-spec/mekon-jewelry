MEKON — საიტის სრული ასლი

1. პირდაპირ გასახსნელად ორჯერ დააწკაპუნეთ MEKON.html-ზე.
   სურათები, შრიფტები, კოლექცია და ანიმაცია ფაილშია ჩაშენებული.

2. საიტის საწყისი HTML, CSS, JavaScript და ყველა რესურსი არის dist საქაღალდეში.
   ჰოსტინგზე ასატვირთად გამოიყენეთ dist-ის შიგთავსი.

3. საწყისი პროექტის ადგილობრივად გასაშვებად საჭიროა Node.js:
   გახსენით ტერმინალი ამ საქაღალდეში და გაუშვით: npm run dev
   შემდეგ გახსენით http://127.0.0.1:4173
   npm install საჭირო არ არის.

Instagram-ისა და სხვა გარე ბმულებისთვის საჭიროა ინტერნეტი.
